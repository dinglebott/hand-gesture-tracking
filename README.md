## ABOUT PROJECT
This is a fun project that uses the inbuilt computer webcam to identify and parse hand gestures as input for various purposes, such as minigames or OS functions.

## FILES
`hand_landmarker.task` is the model that detects hand gestures, downloaded from Google's MediaPipe.
`peace_detector.py` is a basic proof-of-concept script that detects peace signs and prints to the console when triggered.
`cow_spinner.py` overlays a cow image that can be manipulated. Pinch your thumb and index finger on the cow and move it around, or use 2 hands to rotate or scale it.
